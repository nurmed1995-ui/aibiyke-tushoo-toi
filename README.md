# Айбийке — Тушоо той сайты

## Данные мероприятия
- Дата: 1 ноября 2026 года, 14:00 (Бишкек, UTC+6)
- Место: ZAMAN, улица Курманжан Датка, 321, Бишкек
- Языки: кыргызский и русский
- Визуальный стиль: нежный детский, пастельно-розовые полосы, цветочные/сказочные мотивы и элегантная типографика
- Первый экран: приглашение открывается по нажатию «Ачуу үчүн басыңыз»
- Музыка: встроенный YouTube-плеер «Бегиш — Кызым», запускается при нажатии на стартовый экран; отдельная карточка/название трека в основном приглашении убраны
- RSVP: открывает WhatsApp на номер +996 550 131 995 с подготовленным сообщением

## Перед отправкой
1. Точное начало припева в `index.html` регулируется переменной `CHORUS_START_SECONDS` (сейчас 24 секунды как предварительная точка; её нужно проверить вручную).
2. Встроенная музыка зависит от доступности YouTube и может не воспроизводиться в некоторых сетях или настройках браузера. Запуск инициируется нажатием гостя, но iOS может ограничивать сторонние iframe-плееры.
3. WhatsApp не отправляет сообщение сам: после открытия WhatsApp гость должен нажать кнопку отправки. Это штатное поведение WhatsApp-ссылок.
4. Карта ведёт на поиск по адресу ZAMAN, Курманжан Датка, 321, Бишкек.

## Обновление опубликованного сайта
1. Откройте GitHub-репозиторий `aibiyke-tushoo-toi`.
2. Откройте `index.html`, нажмите значок карандаша (Edit this file).
3. Замените содержимое новым `index.html` целиком или загрузите обновлённый файл через Add file → Upload files и подтвердите Commit changes.
4. Vercel автоматически начнёт новое развёртывание после коммита. Ссылка на сайт обычно останется прежней.
