# Айбийке — Тушоо той сайт-приглашение

## Публикация на GitHub + Vercel
1. Распакуйте ZIP-архив.
2. В репозитории GitHub `aibiyke-tushoo-toi` нажмите **Add file → Upload files**.
3. Загрузите **оба файла из архива**: `index.html` и `cover-art.jpg` (картинка используется на первой странице).
4. Нажмите **Commit changes**. Vercel автоматически пересоберёт сайт.
5. Откройте публичную ссылку и нажмите на обложку, чтобы открыть приглашение. Вся страница прокручивается вниз; музыку браузер может запускать только после нажатия.
