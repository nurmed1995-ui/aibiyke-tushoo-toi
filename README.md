# Айбийке — Тушоо той

## Файлдар
- `index.html` — адаптивдүү чакыруу сайты.
- `aibiyke-bear-4k.mp4` — кыймылдуу аюу менен биринчи экрандын видеосу.
- `nursery-pattern.jpg` — сиз жиберген пастелдүү балдар обоиунун негизинде даярдалган фон үлгүсү.
- `floral-side-strips.jpg` — сиз жиберген гүлдүү чакыруу үлгүсүнөн алынган каптал жасалгалар.

Эски статикалык обложка бул жаңыртылган архивге киргизилген эмес. Биринчи экран видеону колдонот.

## GitHub аркылуу жаңыртуу
1. Репозиторийдин түпкү папкасына ушул архивден төрт файлды жүктөңүз: `index.html`, `aibiyke-bear-4k.mp4`, `nursery-pattern.jpg`, `floral-side-strips.jpg`.
2. GitHub'да `Commit changes` басыңыз.
3. Vercel автоматтык түрдө жаңы версияны жарыялайт.

## Маанилүү
- Биринчи экрандагы видео үнсүз автоматтык кайталанып ойнойт; чакыруу баскычы видеонун үстүндө жайгашкан.
- Ички барактарда сиз жиберген референстердин негизинде пастелдүү фон, гүлдүү каптал жасалгалар жана канат кагып учкан CSS-бабочкалар колдонулат.
- Музыка YouTube'дан ишке кирет жана 18-секунддан баштоого аракет кылат. Аудио ойнотуу YouTube жана мобилдик браузердин чектөөлөрүнө көз каранды.
- WhatsApp формасы даяр билдирүүнү ачат; конок WhatsApp ичинде өзү жөнөтөт.
- Карта Google Maps издөөсүн ачат; ресторандын так pin-ордун өзүнчө текшерүү сунушталат.
