# Айбийке — Тушоо той

## Файлдар
- `index.html` — адаптивдүү чакыруу сайты.
- `cover-art.jpg` — баштапкы бет үчүн сиз берген обложка.

## GitHub аркылуу жаңыртуу
1. Эки файлды тең репозиторийдин түпкү папкасына жүктөңүз: `index.html` жана `cover-art.jpg`.
2. `Commit changes` басыңыз.
3. Vercel автоматтык түрдө кайра жарыялайт.

## Маанилүү
- Баштапкы беттеги баскыч чакырууну ачат; андан кийин баракты ылдый жылдырууга болот.
- Музыка YouTube'дан жүктөлөт жана браузердин/тармактын жөндөөлөрүнө жараша иштеши мүмкүн. Браузер аудиону бөгөттөсө, төмөнкү «Музыка» баскычын колдонуңуз.
- WhatsApp формасы алдын ала даярдалган билдирүүнү ачат; конок WhatsApp ичинде өзү жөнөтөт.
- Карта Google Maps издөөсүн ачат; ресторандын так pin-ордун жарыялоодон мурун текшерип коюңуз.
