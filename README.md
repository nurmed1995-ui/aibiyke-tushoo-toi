# Айбийке — Тушоо той: обновлённый мобильный сайт

## Файлы для GitHub
Все нужные файлы находятся в корне архива — папка `assets/` не нужна.

- `index.html` — обновлённый сайт.
- `aibiyke-bear-4k.mp4` — видео-обложка в мобильном H.264 Baseline / MP4, 1080×1920, 24 fps. Имя оставлено таким же, как в текущем GitHub-репозитории, чтобы заменить старый файл. Исходное видео было меньше, поэтому это мобильная оптимизированная версия, а не настоящее 4K-видео. В видео уже скомпонованы присланный фон с карусельными лошадками и цветочные боковые поля, чтобы белый фон ролика не перекрывал оформление на iPhone/Android.
- `bear-poster.jpg` — кадр, извлечённый из видео, используется только как временное изображение пока видео загружается.
- `background-music.mp3` — твой аудиофайл, обрезанный с исходной 18-й секунды; в самом файле записано плавное 3-секундное нарастание громкости и мягкое затухание в конце.
- Изображения для оформления: `carousel-illustration.jpg`, `floral-edge-left.jpg`, `floral-edge-right.jpg`, `nursery-wallpaper.jpg`, `pink-empty-frame.jpg`, `ribbon-edge-left.jpg`, `ribbon-edge-right.jpg`, `scallop-edge-left.jpg`, `scallop-edge-right.jpg`, `teddy-cutout.png`, `watercolor-bow.jpg`.

## Обновление опубликованного сайта
1. Распакуйте архив.
2. В GitHub откройте репозиторий `aibiyke-tushoo-toi`.
3. Нажмите **Add file → Upload files** и перетащите/выберите все файлы из распакованного архива прямо в корень репозитория. Если GitHub спросит подтверждение замены файла, подтвердите для `index.html` и `aibiyke-bear-4k.mp4`.
4. Нажмите **Commit changes** и дождитесь автоматического развёртывания в Vercel.
5. Откройте прежнюю ссылку. При необходимости обновите страницу через Ctrl+F5 или откройте её в приватном окне.

Старые `cover-art.jpg`, `nursery-pattern.jpg` и `floral-side-strips.jpg` можно пока не трогать: обновлённый код их не использует. Новая обложка использует видео, его собственный кадр-заставку и обои `nursery-wallpaper.jpg` с цветочными боковыми деталями.

## iPhone и Android
- Видео: MP4, H.264 Baseline, yuv420p, fast-start, muted/autoplay/loop/playsinline. При нажатии на обложку код также вызывает `video.play()` повторно.
- Музыка: локальный MP3 вместо YouTube; отдельной кнопки «Музыка» нет. Воспроизведение запускается прямо при нажатии «АЧУУ ҮЧҮН БАСЫҢЫЗ».
- WhatsApp: форма открывает `+996 550 131 995` с готовым сообщением; гость должен нажать «Отправить» внутри WhatsApp.

Я проверил структуру файлов и синтаксис JavaScript, но не могу удалённо гарантировать поведение на каждом телефоне без реального теста на iPhone/Safari и Android/Chrome.
