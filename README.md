## Музыка и припев
Из-за ограничений браузеров музыка начинает играть после нажатия посетителем кнопки. В проект добавлен официальный аудиотрек на YouTube через встроенный плеер. Переменная `CHORUS_START_SECONDS` в `index.html` сейчас установлена в `24` секунды как начальная точка для проверки. **Точное начало припева я не могу подтвердить**, поэтому перед рассылкой откройте официальный трек, найдите точную секунду припева и поправьте это значение. После этого кнопка будет перематывать к заданной секунде и запускать воспроизведение.

Официальный аудиотрек: https://www.youtube.com/watch?v=HpoVxozi5FY

Важно: встроенный плеер зависит от доступности YouTube и его настроек. Некоторые браузеры или сети могут ограничивать воспроизведение.

## Публикация на Vercel через GitHub
1. Распакуйте ZIP.
2. Создайте репозиторий на https://github.com/new и загрузите в него `index.html`.
3. Откройте https://vercel.com/new, подключите GitHub, выберите репозиторий и нажмите **Deploy**.
4. После успешного развёртывания Vercel выдаст публичную ссылку вида `имя-проекта.vercel.app`.
5. При обновлении файла в GitHub Vercel обычно автоматически публикует новую версию.

Документация Vercel: https://vercel.com/docs/deployments/overview
